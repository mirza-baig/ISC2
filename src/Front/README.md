# ISC2 Next.js Application

## Setup

[Make sure you are connected to the VPN to run the app](https://iscsquared.atlassian.net/wiki/spaces/APPS/pages/3458498765/VPN+Access+Steps+for+new+developer).

1. `npm install`
2. `npm run bootstrap`
3. `npm run next:dev`
